# Estimated jersey numbers

A season with no recorded number on a club uses the number from the **next season after it on that same club** (or the closest
earlier season if there is no later one). These are shown in the circle tooltip as "number estimated for <year>".
When a real number is obtained, set `num` on that player's Regular season row in `players.json` and the estimate disappears.
